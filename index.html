EastTown and Project:YeroGrid HTML Portal

The most generic HTML portal out there currentlly, probably.

About this:

This is meant mostly for people working on these projects, altough I don't think anyone else could get use out of this. Both Project:YeroGrid and EastTown have downloadable links on Google Drive, and if you're here, I'm going to assume you already know about this.

This page aims to only show a couple of links for each project that is currently being worked on, and as this isn't made for the public, do not expect more convenient things from this.

  • Pretty much nay project ( started after Project:YeroGrid ) that has been worked on long enough will have a section here. Some projects that have been worked on for longer might even have their own special page, which you can access by clicking on the project title if it is a hyperlink. Or, of course, just use Github to navigate it.

    • However, not all projects that should have a page will have one. For example, I will most probably make a page for Project:YeroGrid to exercise my HTML skills a bit more, but EastTown won't have one since it is not necessarry, nor is it developed enough to have something more than a basic description.

    Browse the files here or on it's Github page.
