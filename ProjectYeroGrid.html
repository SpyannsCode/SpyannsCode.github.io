Project:YeroGrid

Controls

General:

  • ~: Go back to the main menu
  • (Shift + ) W, A, S, D or Arrow Keys: Move The Camera Around
  • Alt: Bring the Camera back to The Center
  • Q: Go Down a Y Level
  • E: Go Up a Y Level
  • Arrow Keys: Select the type of arrow to place down
  • W, A, S, D: Same as Arrow Keys
  • Shift + WASD/Arrow Keys: Move The Camera Around
  • ALT: Reset The Camera
  • Scroll Wheel: Change Camera Zoom
  • ESC: Pause
  • Mouse Left-Click: Place Tile
  • Mouse Right-Click or Hold: Interact with object
  • R: Rotate the selected tile π/2

In Puzzle Mode:

  • Holding P: Hides The Puzzle Details
  • Holding TAB: Brings up the Help Menu ( CURRENTLY OUTDATED, PLEASE REFER BACK TO THIS PAGE FOR HELP )
  • T: Start / Stop

In Real-Time Mode:

  • Holding TAB: Brings up the Help Menu ( CURRENTLY OUTDATED, PLEASE REFER BACK TO THIS PAGE FOR HELP )

In Editor Mode:

  • CTRL + S: Saves the progress
  • CTRL + L: Loads the last save
  • Holding Down The Middle Mouse Button: Selects a square area. ACTIONS:
    • Holding a Mouse Button ( During ): Selects the action to perform after the area is selected.
    • Releasing The Middle Mouse Button: Selects The Area.
    • Pressing The Left Mouse Button ( After ): Places copies of the selected tile in the area on your Y level.
    • Pressing The Left Mouse Button ( After ): Deletes all tiles in the area on your Y level. ( Note: Some tiles like minions might not get deleted )
  • Holding TAB: Brings up the Help Menu ( CURRENTLY OUTDATED, PLEASE REFER BACK TO THIS PAGE FOR HELP )
  • Number Keys: Switch the current tile to the tile corresponding to the numbered key from the hotbar.
  • Holding 0 + A Number Key: Switch the tile corresponding to the numbered key from the hotbar to the currently selected tile.
